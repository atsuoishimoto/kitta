# Store listing drafts

Submission texts for Microsoft Store (and other listings), based on the
product plan (§2, §28). Screenshots must be taken on a real machine and

## Name

**Kitta — Offline AI Background Remover**

日本語: **Kitta — 無料・オフラインAI背景除去**

## Short description

> Compare AI background removal models side by side. Fully offline.

日本語:

> AI背景除去を、比べて選ぶ。

## Description (English)

Kitta runs the same image through multiple open background-removal AI
models and shows the results side by side — because different images
need different models.

- Compare several AI models on your own image with one drag & drop
- Synchronized zoom and pan to inspect edges, hair and fine detail
- Checker / white / black backgrounds to spot fringes and halos
- Save the best result as a transparent PNG, or save the alpha mask
- Copy results straight to the clipboard
- Command-line interface for batch processing folders of images
- 100% offline: your images never leave your computer. No cloud, no
  upload, no account. Network access is used only to download the AI
  models on first use and for images you explicitly drag from the web

Kitta is free software (GPL-3.0-or-later) built on open models such as
U²-Net, ISNet/DIS and BiRefNet.

## Description (日本語)

Kitta は、同じ画像を複数のオープンな AI 背景除去モデルで処理し、結果を
横に並べて比較できるデスクトップアプリです。画像によって得意なモデルは
違う — だから比べて選ぶ。

- ドラッグ&ドロップだけで複数 AI モデルの結果を並べて比較
- 同期ズーム/パンで髪の毛や輪郭のディテールを確認
- チェッカー / 白 / 黒背景でフリンジやにじみをチェック
- ベストな結果を透過 PNG で保存、アルファマスクの保存も可能
- 結果をそのままクリップボードへコピー
- フォルダ一括処理ができる CLI 付き
- 100% オフライン: 画像が PC の外に送られることはありません。通信は
  初回のモデルダウンロードと、ユーザーが明示的に Web からドラッグした
  画像の取得のみ

Kitta は U²-Net / ISNet(DIS) / BiRefNet などのオープンモデルを利用した
フリーソフトウェア（GPL-3.0-or-later）です。

## Promotion angle (§28)

Do not present Kitta as "another free background remover". Lead with:

> I built an offline app that lets you run the same image through
> multiple open background-removal AI models and compare the results
> side by side.

One screenshot: the same image, three models, visibly different results,
captioned "Same image. 100% offline."
